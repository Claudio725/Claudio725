## 💼 Meus Principais Projetos do Portfólio

Aqui estão alguns dos projetos em destaque que desenvolvi:

### 1. Bíblia NVT
* **Descrição:** App desenvolvido para a Editora Mundo Cristão para consulta de livros, capítulos e versículos da NVT..
* **Tecnologias utilizadas:** `Swift`, `SwiftUI`, Banco de Dados local Sqlite 
* **Principais recursos:** 
  * Notificações - marcações de textos
  * Streaming de áudio - o app consumia arquivos mp3 para poder fazer a leitura personalizada conforme o versículo escolhido.
  * Compartilhamento de textos
  * Cópia de textos
  * Lista de versículos marcados
  * Navegação entre livros, capítulos e versículos
  * Navegação inteligente entre livros
  * Ajustes do sistema para permitir escolha de Fontes e Modo Noturno

### 2. DayPay
* **Descrição:** App desenvolvido para a empresa E-Frame Tecnologia e Negócios, com o objetivo de
* realizar criação de remessas para a execução de transferências monetárias entre países. Este
* app foi criado nas duas plataformas nativas IOS e Android.
* **Tecnologias utilizadas:** Swift, SwiftUI, Apis restful, Storyboard, KingFischer, Java para Android
* ** Principais recursos:**
* Notificações de remessas criadas
* Tratamento de imagens
* Consumo de Apis restful
* Navegação inteligente dos processos de criação das remessas
* Pagamento de remessas
* Conversão monetária entre países (dólar, euro e real).
